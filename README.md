## Como adicionar um cliente
1. Criar diretório `nome-do-cliente/` com o `index.html` (arquivo único, links relativos)
2. Atualizar a tabela acima
3. Commit + push — o site entra no ar em ~1 min em `tiagopolidoro.github.io/sites/nome-do-cliente/`

## Regras da casa
- Site = arquivo único autocontido (HTML + imagens embutidas)
- Links internos sempre relativos (`pagina.html`, nunca `/pagina.html`)
- Nada de dados sensíveis ou assets de marca dos clientes aqui — isso fica no arquivo privado
